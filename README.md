## Overview

Subnautica Base Planner is a companion web app for planning Subnautica base constructions, providing a 3D-capable layout editor for placing rooms, corridors, and modules, calculating hull integrity points and required reinforcements, estimating power consumption vs generation capacity, and tracking material costs for the entire planned base.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Subnautica Base Planner** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **3D Layout** | Place base rooms and corridors in a 3D grid layout editor |
| **Hull Integrity** | Calculates net hull integrity and required reinforcement count |
| **Power Balance** | Calculates total power consumption vs available generation capacity |
| **Material Cost** | Full bill of materials for the planned base construction |
